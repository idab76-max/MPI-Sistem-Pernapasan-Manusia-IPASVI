PAKET MPI ONLINE — SD NEGERI 8 KODEOHA

Isi paket:
- index.html: aplikasi MPI siap diunggah ke hosting statis.
- PANDUAN_PUBLIKASI.md: panduan publikasi gratis menggunakan GitHub Pages.

Cara uji sebelum publikasi:
1. Ekstrak ZIP.
2. Buka index.html dengan Chrome, Edge, Firefox, atau Safari.
3. Uji menu Materi Organ, Alur Udara, Simulasi, Jaga Kesehatan, Kuis, Profil, dan Selesai.

Aplikasi mandiri: tidak membutuhkan instalasi, server backend, database, atau pustaka eksternal. Setelah online, internet diperlukan untuk membuka alamat website pertama kali. Setelah file sudah terbuka, materi utama berjalan di browser. Skor kuis dan jawaban refleksi tidak dikirim ke server dan tidak tersimpan sebagai data kelas.
